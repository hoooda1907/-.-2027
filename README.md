# أسواق بدر — استعلام الأسعار والجرد (الإصدار 3)

## الدخول
- المستخدم: `1111` — كلمة المرور: `1111` (يستطيع إنشاء حسابات إضافية من قسم «الحسابات»).
- كلمة مرور إنهاء الجرد = كلمة مرور أي حساب «مدير» (الافتراضي 1111).
- الحساب الرئيسي المخفي له قسم إضافي «تجميع الجرد» ولا يظهر لأي حساب آخر.

## الأقسام
- استعلام الأسعار
- الجرد: باركود غير موجود = رسالة فقط دون إضافة. يسأل عن اسم الموظف والفرع عند البدء، حفظ تلقائي بعد كل عملية، يعرض آخر 5 عمليات فقط، زر «تصدير الجرد».
- الحسابات (للمدير فقط) — تجميع الجرد (للحساب الرئيسي فقط).

## أماكن الحفظ
- ويندوز: سطح المكتب ← Aswaq Badr ← «الجرد» (شيتات الجرد) و«تجميع الجرد» (نتائج التجميع).
- اسم شيت الجرد: `الاسم الفرع اليوم الشهر` مثل: محمود شارع الإسكندرية 17 نوفمبر.
- أندرويد: Documents/AswaqBadr (وزر «تصدير الجرد» يفتح قائمة المشاركة).

## البناء (GitHub Actions)
ارفع كل المحتويات (بما فيها .github) ثم شغّل Build Aswaq Badr. ستحصل على:
1. `AswaqBadr-Windows-10-11` — ويندوز 10 و11.
2. `AswaqBadr-Windows-7-8-10-11-AllInOne` — نسخة واحدة تعمل على كل ويندوز (7 وما بعده، 32 و64 بت).
3. `AswaqBadr-Android-APK` — أندرويد.

التطوير محليًا: `npm install` ثم `npm start`.
